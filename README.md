# flag-icons

Circular country flag icons (SVG), named by ISO 3166-1 alpha-2 code.

Usage (jsDelivr CDN):

```
https://cdn.jsdelivr.net/gh/duan0115/flag-icons@main/flags/<code>.svg
```

Example: `flags/nl.svg` is the Netherlands, `flags/jp.svg` is Japan.
`xk.svg` is Kosovo (not an ISO code, included by the source set).

Source: converted/collected from the circle-flags project by HatScripts
